# Checklist PRISMA 2020 (ringkasan kerja)

Ringkasan berbahasa Indonesia untuk memeriksa naskah. **Bukan pengganti** checklist
resmi: untuk lampiran naskah, unduh checklist asli dari situs PRISMA dan isi
nomor halamannya. Rujukan: Page et al. (2021) dan penjelasannya (Page et al., 2021b).

Kolom "Lokasi" diisi bagian/halaman naskah. Butir yang tidak berlaku ditulis
"N/A" beserta alasan, jangan dikosongkan.

| # | Bagian | Butir | Lokasi |
|---|---|---|---|
| 1 | Judul | Judul menyebut naskah ini tinjauan sistematis | |
| 2 | Abstrak | Abstrak terstruktur (lihat checklist PRISMA 2020 untuk abstrak) | |
| 3 | Pendahuluan | Rasional tinjauan dalam konteks pengetahuan yang ada | |
| 4 | Pendahuluan | Tujuan atau pertanyaan tinjauan yang eksplisit | |
| 5 | Metode | Kriteria inklusi/eksklusi dan cara pengelompokan studi untuk sintesis | |
| 6 | Metode | Semua sumber yang dicari (basis data, register, situs, penelusuran sitasi) dan tanggal terakhir pencarian | |
| 7 | Metode | Strategi pencarian lengkap untuk semua basis data, termasuk filter dan batasan | |
| 8 | Metode | Proses seleksi: jumlah reviewer, independen atau tidak, alat otomatis yang dipakai | |
| 9 | Metode | Proses pengumpulan data: jumlah pengumpul, independen atau tidak, konfirmasi ke penulis, alat otomatis | |
| 10a | Metode | Daftar dan definisi *outcome* yang dicari | |
| 10b | Metode | Variabel lain yang dicari (karakteristik peserta, intervensi, pendanaan) dan asumsi untuk data yang hilang | |
| 11 | Metode | Metode penilaian risiko bias studi: alat, jumlah penilai, independen atau tidak | |
| 12 | Metode | Ukuran efek per *outcome* (bila ada sintesis kuantitatif) | |
| 13a | Metode | Cara memutuskan studi mana yang masuk tiap sintesis | |
| 13b | Metode | Persiapan data untuk penyajian atau sintesis | |

| 13d | Metode | Metode sintesis dan alasannya | |
| 13e | Metode | Cara menelusuri heterogenitas | |
| 13f | Metode | Analisis sensitivitas | |
| 14 | Metode | Penilaian risiko bias pelaporan (bias publikasi) | |

| 17 | Hasil | Sitasi dan karakteristik setiap studi yang masuk | |

| 20a | Hasil | Ringkasan karakteristik dan risiko bias studi per sintesis | |

| 23b | Diskusi | Keterbatasan bukti yang ditinjau | |
| 23c | Diskusi | Keterbatasan proses tinjauan | |

| 24a | Lain | Registrasi (nama register dan nomor) atau pernyataan tidak diregistrasi | |
| 24b | Lain | Lokasi protokol, atau pernyataan tidak ada protokol | |
| 24c | Lain | Amandemen terhadap registrasi/protokol | |
